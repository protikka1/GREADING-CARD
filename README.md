# Greading Card - Hello Android

Welcome to my first Android Studio project! This is a simple "Hello World" style application that displays a greeting card.

## 📱 Project Description
This project is a basic Android application built using **Jetpack Compose**. It serves as an introduction to Android development, focusing on UI layout and project structure.

## ✨ Features
- Simple and clean UI using Jetpack Compose.
- Displays a personalized greeting message.
- Demonstrates the use of Text and Surface components.

## 🛠️ Built With
- **Language:** Kotlin
- **UI Framework:** Jetpack Compose
- **Build System:** Gradle
- **IDE:** Android Studio

## 🚀 How to Run
1. Clone this repository:
   ```bash
   git clone git@github.com:protikka1/GREADING-CARD.git
   ```
2. Open the project in **Android Studio**.
3. Let Gradle sync and build the project.
4. Run the app on an **Emulator** or a **Physical Device**.
